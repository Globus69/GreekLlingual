### **3.3 Integration Test: Config → Content → Game**

**Vollständiger Workflow testen:**

1. **Erstelle Config für Item X:**
   - Matching aktiviert, Threshold = 0

2. **Erstelle Content für Item X:**
   - Mode: "matching"
   - 6 Paare (Greek + English)

3. **Spiele Game:**
   - Gehe zu `/practice-modes`
   - Finde Item X
   - Klicke "🎮 Matching"

**Erwartete Ergebnisse:**
- [ ] Game lädt mit korrekten Content
- [ ] 6 Paare werden angezeigt
- [ ] Question Text korrekt
- [ ] Instructions korrekt
- [ ] Score wird gespeichert

---

### **3.4 Error Handling testen**

**Test-Szenarien:**

#### **3.4.1 Duplikate verhindern**
- Versuche 2× Config für dasselbe Item zu erstellen
- **Erwartet:** Error-Message oder Unique-Constraint-Fehler

#### **3.4.2 Ungültige JSON Distractors**
- Gib invalides JSON ein: `["test", "test2"]` (fehlende Anführungszeichen)
- **Erwartet:** Validation Error

#### **3.4.3 Threshold außerhalb Range**
- Setze Threshold = -1 oder 100
- **Erwartet:** Validation Error (sollte 0-3 sein)
