# Versionierung

Dieses Dokument hält die Versionshistorie des Projekts fest. Wir verwenden das **BETA** Schema, beginnend bei **BETA 0.7.9**. Jeder Deploy erhöht die Versionsnummer nach folgendem Muster:

- **BETA 0.8.0** – erster größerer Release nach 0.7.9
- **BETA 0.8.1** – Patch‑Release
- **BETA 0.8.2** …
- **...** – weitere Patch‑Releases bis **BETA 0.8.9**
- **BETA 0.9.0** – nächster Minor‑Release

## Änderungshistorie (Beispiel)

| Datum       | Version      | Änderung                              |
|------------|--------------|---------------------------------------|
| 2026-02-23 | BETA 0.7.9  | Initiale BETA‑Version für das Manual |
| 2026-02-24 | BETA 0.8.0  | Erstes Feature‑Release (User‑Manual) |
| 2026-02-25 | BETA 0.8.1  | Bug‑Fix: Refresh‑User‑Logik            |
| 2026-02-26 | BETA 0.8.2  | UI‑Verbesserungen für Mobile‑Dashboard |
| 2026-02-27 | BETA 0.8.3  | Dokumentation aktualisiert            |
| …          | …            | …                                     |
| 2026-03-01 | BETA 0.8.9  | Letzter Patch vor Minor‑Release       |
| 2026-03-02 | BETA 0.9.0  | Minor‑Release: neue Module hinzugefügt |

> **Hinweis:** Bei jedem Deploy wird die Versionsnummer gemäß diesem Schema erhöht und hier eingetragen.
