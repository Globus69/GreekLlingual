# AI Guidelines – Hellenic Horizons GreekLingua Dashboard  
(gültig ab Februar 2026 – bitte immer beachten!)

## 1. Immer zwingend zu berücksichtigende Parameter & Prinzipien

- **App-Name & Kontext**  
  Immer „Hellenic Horizons – GreekLingua Dashboard“ nennen (kein „GreekLingua“ allein, kein „HH Dashboard“)

- **Sprache & Stil**  
  Modernes Griechisch (Dimotiki), freundlich, klar, lernfreundlich  
  Keine Katharevousa, keine übertrieben formellen Formen

- **Wichtige Konstanten / Limits** (nicht verändern ohne Absprache)  
  - Max. neue Karten pro Tag: 20  
  - Review-Intervall-Algorithmus: angepasstes SM-2 (Faktor 2.5 → 2.0 bei Schwierigkeitsstufe < 3)  
  - Daily Phrases: genau 3 pro Tag (Morgen, Mittag, Abend)  
  - Keine Duplikate in einem 30-Tage-Fenster

- **Verbote / No-Gos**  
  - Keine Google Translate / DeepL-Texte ohne Nachbearbeitung  
  - Keine generischen Platzhalter-Sätze („Der Hund bellt“)  
  - Keine politisch/sensiblen Themen in Beispielsätzen  
  - Keine Änderung der Ordnerstruktur ohne explizite Freigabe

## 2. Prompting-Best-Practice für dieses Projekt

- Immer die aktuelle START.md und diese ai-guidelines.md referenzieren  
- Code-Änderungen: immer diff-Format + Erklärung warum  
- Neue Features: erst User Story → dann technische Umsetzung  
- Bei Unsicherheit: lieber nachfragen als falsch annehmen
