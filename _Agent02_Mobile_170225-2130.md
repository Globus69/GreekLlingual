## 📱 SCHRITT 3: VOCABULARY MOBILE PAGE ERSTELLEN (60 Min)

### **3.1 Page Structure (20 Min)**

**Erstelle:** `src/app/m/vocabulary/page.tsx`

**Layout:**
```tsx
'use client';

import { useState, useEffect } from 'react';
import { useRouter } from 'next/navigation';
import { useAuth } from '@/context/auth-context';
import { supabase } from '@/db/supabase';

export default function MobileVocabularyPage() {
  const { user, isAuthenticated } = useAuth();
  const router = useRouter();
  const [cards, setCards] = useState([]);
  const [currentIndex, setCurrentIndex] = useState(0);
  const [isFlipped, setIsFlipped] = useState(false);
  const [loading, setLoading] = useState(true);

  // Auth check
  useEffect(() => {
    if (!isAuthenticated) {
      router.push('/login-pin');
    }
  }, [isAuthenticated, router]);

  // Fetch Due Cards (FSRS-6)
  useEffect(() => {
    if (user?.id) {
      fetchDueCards();
    }
  }, [user]);

  async function fetchDueCards() {
    setLoading(true);
    const { data, error } = await supabase
      .rpc('get_due_cards_fsrs', {
        p_student_id: user.id,
        p_module: 'vocabulary',
        p_limit: 20 // Mobile: Kleine Batches!
      });

    if (error) {
      console.error('Error fetching cards:', error);
      setCards([]);
    } else {
      setCards(data || []);
    }
    setLoading(false);
  }

  return (
    <div style={{
      minHeight: '100vh',
      backgroundColor: '#0F0F11',
      paddingBottom: '80px'
    }}>
      {/* Header */}
      <MobileHeader title="📚 Vocabulary" />

      {/* Card Interface */}
      {loading ? (
        <LoadingState />
      ) : cards.length === 0 ? (
        <EmptyState />
      ) : (
        <CardInterface
          card={cards[currentIndex]}
          isFlipped={isFlipped}
          onFlip={() => setIsFlipped(!isFlipped)}
          onRate={(rating) => handleRate(rating)}
        />
      )}

      {/* Bottom Navigation */}
      <MobileBottomNav active="home" />
    </div>
  );

  async function handleRate(rating) {
    const card = cards[currentIndex];

    // Update Card (FSRS-6)
    const { error } = await supabase.rpc('update_card_fsrs', {
      p_student_id: user.id,
      p_item_id: card.item_id,
      p_module: 'vocabulary',
      p_rating: rating // 1=Again, 2=Hard, 3=Good, 4=Easy
    });

    if (error) {
      console.error('Error updating card:', error);
      return;
    }

    // Next Card
    setIsFlipped(false);
    setCurrentIndex(currentIndex + 1);

    // Reload if last card
    if (currentIndex + 1 >= cards.length) {
      fetchDueCards();
      setCurrentIndex(0);
    }
  }
}
```

### **3.2 Card Interface Component (40 Min)**

**Card Interface Design (Mobile-optimiert):**

```tsx
function CardInterface({ card, isFlipped, onFlip, onRate }) {
  return (
    <div style={{
      padding: '24px',
      display: 'flex',
      flexDirection: 'column',
      alignItems: 'center',
      minHeight: 'calc(100vh - 200px)'
    }}>
      {/* Progress Indicator */}
      <div style={{
        fontSize: '14px',
        color: '#8E8E93',
        marginBottom: '20px'
      }}>
        Card {currentIndex + 1} / {cards.length}
      </div>

      {/* Card */}
      <div
        onClick={onFlip}
        style={{
          width: '100%',
          maxWidth: '400px',
          minHeight: '300px',
          backgroundColor: 'rgba(255, 255, 255, 0.1)',
          backdropFilter: 'blur(10px)',
          border: '1px solid rgba(255, 255, 255, 0.1)',
          borderRadius: '20px',
          padding: '32px',
          display: 'flex',
          flexDirection: 'column',
          alignItems: 'center',
          justifyContent: 'center',
          cursor: 'pointer',
          transition: 'transform 0.3s ease',
          marginBottom: '32px'
        }}
      >
        {/* Front: Greek Word */}
        {!isFlipped ? (
          <>
            <div style={{
              fontSize: '12px',
              color: '#8E8E93',
              marginBottom: '12px',
              textTransform: 'uppercase',
              letterSpacing: '1px'
            }}>
              Greek
            </div>
            <div style={{
              fontSize: '32px',
              fontWeight: 'bold',
              color: 'white',
              textAlign: 'center'
            }}>
              {card.greek}
            </div>
            <div style={{
              fontSize: '14px',
              color: '#8E8E93',
              marginTop: '20px'
            }}>
              Tap to reveal answer
            </div>
          </>
        ) : (
          /* Back: English Translation */
          <>
            <div style={{
              fontSize: '12px',
              color: '#8E8E93',
              marginBottom: '12px',
              textTransform: 'uppercase',
              letterSpacing: '1px'
            }}>
              English
            </div>
            <div style={{
              fontSize: '28px',
              fontWeight: '600',
              color: 'white',
              textAlign: 'center',
              marginBottom: '16px'
            }}>
              {card.english}
            </div>
            {card.example && (
              <div style={{
                fontSize: '14px',
                color: '#93C5FD',
                textAlign: 'center',
                fontStyle: 'italic'
              }}>
                "{card.example}"
              </div>
            )}
          </>
        )}
      </div>

      {/* Rating Buttons (only when flipped) */}
      {isFlipped && (
        <div style={{
          width: '100%',
          maxWidth: '400px',
          display: 'grid',
          gridTemplateColumns: 'repeat(2, 1fr)',
          gap: '12px'
        }}>
          <RatingButton
            label="Again"
            emoji="❌"
            color="#FF3B30"
            onClick={() => onRate(1)}
          />
          <RatingButton
            label="Hard"
            emoji="😰"
            color="#FF9500"
            onClick={() => onRate(2)}
          />
          <RatingButton
            label="Good"
            emoji="✅"
            color="# 34C759"
            onClick={() => onRate(3)}
          />
          <RatingButton
            label="Easy"
            emoji="😊"
            color="#007AFF"
            onClick={() => onRate(4)}
          />
        </div>
      )}
    </div>
  );
}

function RatingButton({ label, emoji, color, onClick }) {
  return (
    <button
      onClick={onClick}
      style={{
        minHeight: '64px', // Large touch target!
        backgroundColor: `${color}22`, // 22 = 13% opacity
        border: `2px solid ${color}`,
        borderRadius: '16px',
        color: color,
        fontSize: '16px',
        fontWeight: '600',
        cursor: 'pointer',
        display: 'flex',
        flexDirection: 'column',
        alignItems: 'center',
        justifyContent: 'center',
        gap: '4px',
        transition: 'all 0.2s ease'
      }}
      onMouseDown={(e) => {
        e.currentTarget.style.transform = 'scale(0.95)';
      }}
      onMouseUp={(e) => {
        e.currentTarget.style.transform = 'scale(1)';
      }}
    >
      <span style={{ fontSize: '24px' }}>{emoji}</span>
      <span>{label}</span>
    </button>
  );
}
```

## 💡 TIPPS

**FSRS-6 Rating System:**
- Rating 1 = Again (❌) - "I need to see this card again soon"
- Rating 2 = Hard (😰) - "This was difficult"
- Rating 3 = Good (✅) - "I got it right"
- Rating 4 = Easy (😊) - "Too easy!"

**Mobile Card Design:**
- Large Font (32px Greek, 28px English)
- Tap to Flip (no hover on mobile)
- Big Rating Buttons (64px height minimum)
- Glassmorphism Background (blur + opacity)

**Data Fetching Best Practices:**
- Small Batches (20 cards max)
- Preload next 3 cards
- Cache in localStorage (offline support)
