### **3.2 Practice Items List Component (30 Min)**

**Erstelle:** Component in gleicher Datei (erstmal)

**Design (Mobile-optimiert):**
```tsx
function PracticeItemsList() {
  const [items, setItems] = useState([]);

  // Fetch Practice Items (RPC: get_practice_config oder aus DB)

  return (
    <div style={{ padding: '16px' }}>
      <h2>Available Practice Items</h2>

      <div style={{
        display: 'flex',
        flexDirection: 'column',
        gap: '12px'
      }}>
        {items.map(item => (
          <PracticeItemCard key={item.id} item={item} />
        ))}
      </div>
    </div>
  );
}
```

**PracticeItemCard:**
- **Layout:** Horizontal Card (Icon | Content | Button)
- **Icon:** Emoji (🎮, 🎯, ✍️)
- **Content:** Item Title + Threshold Info
- **Button:** "Start Practice" oder "🔒 Locked"
- **Touch Target:** Min 56px height
- **Style:** Glassmorphism (wie Stats Cards)

**States:**
- Unlocked: `bg-white/10`, border `border-white/20`
- Locked: `bg-white/5`, border `border-white/10`, opacity `0.6`
- Hover: `bg-white/15` (auf Mobile = tap feedback)

**Checklist:**
- [ ] Items werden geladen (RPC oder Mock Data)
- [ ] Cards zeigen korrekte Info
- [ ] Lock/Unlock State funktioniert
- [ ] Touch-Friendly (min 56px height)
- [ ] Glassmorphism Style applied

### **Bottom Sheet:**
```tsx
<div style={{
  position: 'fixed',
  bottom: 0,
  left: 0,
  right: 0,
  zIndex: 1000,
  backgroundColor: 'rgba(28, 28, 30, 0.95)',
  backdropFilter: 'blur(20px)',
  borderTopLeftRadius: '20px',
  borderTopRightRadius: '20px',
  maxHeight: '80vh',
  overflowY: 'auto'
}}>
  {/* Handle Bar */}
  <div style={{
    width: '40px',
    height: '5px',
    backgroundColor: 'rgba(255,255,255,0.3)',
    borderRadius: '3px',
    margin: '12px auto'
  }} />

  {/* Content */}
</div>
```

### **Glassmorphism:**
```css
backgroundColor: 'rgba(255, 255, 255, 0.1)',
backdropFilter: 'blur(10px)',
border: '1px solid rgba(255, 255, 255, 0.1)',
```
